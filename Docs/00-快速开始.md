# 00 · 快速开始

> 目标：10 分钟内让工程跑起来，并完成第一次改动。

## 1. 环境

| 项 | 要求 |
|---|---|
| Unity | 6000.3.10f1（Unity 6.3，URP 17.3） |
| 模块 | TextMesh Pro、Addressables、Input System（`Active Input Handling` 需包含 Input System） |
| 平台 | Windows 优先；WebGL 有专门适配，移动端部分能力被跳过 |

首次打开会做一次全量导入（Library 约 2.3 GB），慢是正常的。

## 2. 跑起来

1. 打开工程根目录 `Unity/ReunionMovement`。
2. 等 Console 不再出现红色编译错误。
3. 打开场景 `Assets/ReunionMovement/Scenes/StartGame.unity`。
4. 按 Play。

按下 Play 之后的顺序（详见 [01-架构总览](01-架构总览.md)）：

```
Bootstrap（自动，无需场景物件）
  → 创建 [GameEngineDriver] 常驻物体
  → GameEngine.Create()
  → new StartGame() → CreateModules() 注册 14 个系统
  → LaunchAsync：OnBeforeInitAsync → 14 个模块 Init → OnGameStartAsync
  → 加载 "Temp" 场景 → 打开 StartGameUIPlane 启动界面
```

**没有"启动场景物件"**——引擎由 `[RuntimeInitializeOnLoadMethod]` 自动拉起，这是第一阶段重构要改善的点（见 [重构方案](重构方案.md) 阶段 1）。

## 3. 只看一个功能

打开 `Assets/ReunionMovement/Scenes/Example/` 下任意场景直接 Play。场景名以 `Test` / `_` 开头，或包含 `Example` / `UIPlaneScene` / `Music` / `Audio` / `Debug` 时，`Bootstrap` 会标记为测试场景、跳过自动跳转，保留当前场景。

也可以到处放 `Bootstrap.ForceDisable = true;` 彻底关掉自动启动，自己手动驱动引擎。

## 4. 第一次改动

### 改启动后打开哪个窗口

`Core/StartGame.cs` → `OnGameStartAsync()`：

```csharp
await SceneSystem.Instance.LoadScene("Temp", true, null, null);
await UISystem.Instance.OpenWindowAsync(UINames.StartGame);
```

窗口名常量在 `Core/System/UISystem/UINames.cs`。

### 加一个自己的系统

1. 复制 `Assets/ReunionMovement/Documentation/CustomSystem.cs.txt` 到 `Core/System/YourSystem/YourSystem.cs`。
2. 实现 `ICustomSystem`（必须 `Init()` 与 `InitProgress`；按需加 `ISystemUpdatable` / `ISystemDisposable`）。
3. 在 `Core/StartGame.cs` 的 `CreateModules()` 里 `modules.Add(YourSystem.Instance);`。
4. **注意顺序**：列表顺序即初始化顺序，`ResourcesSystem` 必须留在最前面。

> 工具箱（菜单 `ReunionMovement → 工具箱`）提供"复制模块模板"和"定位注册入口"。

### 加一个窗口

菜单 `ReunionMovement → UI工具` 生成面板脚本骨架（已有同名文件不会覆盖），然后：
1. 把窗口名加进 `UINames`；
2. `UISystem.Instance.OpenWindowAsync(name)` 打开。

### 编辑器工具

| 菜单 | 作用 |
|---|---|
| `ReunionMovement → 工具箱` | 环境检查、示例打开、模块模板 |
| `ReunionMovement → 表格处理 → 表格 -> 脚本` | Excel 导表 |
| `ReunionMovement → 打包 → 导出 ReunionMovement.unitypackage` | 出包 |
| `ReunionMovement → Addressables → ...` | 资源迁移 / 构建 / 上传 OSS |

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| Console 报缺 Package | Package Manager 装 Addressables / Input System，等解析完成后刷新 |
| Play 后直接进了 `Temp` 场景，示例场景被换掉 | 场景名没命中测试规则；改名或在 `Bootstrap` 里加判断 |
| 某个系统 `Instance` 拿到了对象但没跑起来 | 它没被注册进 `CreateModules()`。三套获取方式并存是当前已知问题 |
| 日志看不到 | 默认走 `Log`（`[Conditional]`，Release 下被编译掉），编辑器里另可在 `ScreenLogger` 面板看 |
| Addressables 报 Catalog 错误 | 保持 `GameConfig.enableHotUpdate` 关闭先用 Resources 跑通 |
