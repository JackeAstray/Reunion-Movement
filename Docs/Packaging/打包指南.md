# ReunionMovement .unitypackage 打包指南

> 说明：ReunionMovement 作为可分发框架包导出为 `.unitypackage`。本文档独立于 Addressables 文档集（`Docs/Packaging/`），
> 说明打包范围、依赖清单、接收方使用步骤与 Addressables 配置的处理方式（Addressables 相关细节见 `Docs/Addressables/`）。

## 1. 打包方式

### 方式一：一键导出（推荐）
Unity 菜单：`ReunionMovement → 打包 → 导出 ReunionMovement.unitypackage`

导出前工具会自动：
- 检查 `com.unity.addressables` 是否安装（未装则提醒）
- 检查 UI 资源是否已迁移到 Addressables（未迁移仅警告，不影响导出）
- 输出到 `Build/Packages/ReunionMovement.unitypackage` 并打开所在目录

### 方式二：手动导出
`Assets → Export Package…`，勾选 `Assets/ReunionMovement` 全目录，导出。

## 2. 包含 / 排除范围

| 内容 | 是否导出 | 说明 |
| --- | --- | --- |
| `Assets/ReunionMovement/`（运行时 + Editor + Resources + Plugins） | ✅ 导出 | ReunionMovement 全部功能与资源 |
| `Assets/AddressableAssetsData/` | ❌ **不导出** | 项目级配置（分组/Profile/Label），接收方打开项目时自动生成 |
| `Library/`、`Temp/`、`Logs/`、`Build/`、`obj/` | ❌ 不导出 | Unity 临时/构建产物 |
| 接收方项目的 `Assets/AddressableAssets/` | ❌ 不导出 | 属于接收方项目，若需附带迁移好的资源副本请单独导出 |

## 3. 依赖清单（接收方需自行安装）

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| `com.unity.addressables` | 2.9.1 | 运行时核心依赖（会自动带 `com.unity.scriptablebuildpipeline`） |
| Unity 版本 | 6000.3+ | 与 ReunionMovement 开发版本一致 |

> 通过 `Window → Package Manager` 搜索安装 Addressables，或直接编辑 `Packages/manifest.json` 添加 `"com.unity.addressables": "2.9.1"`。

## 4. 接收方使用步骤

1. **导入包**：`Assets → Import Package → Custom Package…` 选择 `ReunionMovement.unitypackage`，全选导入。
2. **安装 Addressables**（见 §3）。
3. **打开项目**：编辑器首次加载时，`AddressablesSetup` 的 `[InitializeOnLoad]` 会自动创建：
   - `Assets/AddressableAssetsData/`（默认配置）
   - 9 个分组（`BuiltIn_Config/UI/Prefabs/Fonts/Shaders`、`Remote_Sounds/Textures/Scenes/AutoDatabase`）
   - 7 个 Label（`builtin/remote/ui/sound/texture/scene/data`）
   - 2 个 Profile（`DevLocal` / `Publish`）
   
   可随时通过菜单 `ReunionMovement → Addressables → 初始化配置` 手动补齐。
4. **（可选）迁移 UI 资源**：菜单 `ReunionMovement → Addressables → 迁移 → UI 资源`，
   将 `Resources/Prefabs/UIs/` 及其依赖复制到 `AddressableAssets/BuiltIn/UI/` 并标记 Addressable。
   不迁移也能运行（异步加载自动降级 Resources）。
5. **（可选）构建 Content**：菜单 `ReunionMovement → Addressables → 构建 Content`，验证 Bundle 构建。
6. **运行**：默认 `LocalOnly` 模式，本地即可运行；远程热更需将 `GameConfig.addressablesMode` 切到 `Remote` 并配置 CDN 地址（Phase 3）。
   - Addressables 相关配置详见 `Docs/Addressables/快速开始.md`；远程部署见 `Docs/Addressables/远程部署指南.md`。

## 5. 关键机制说明

### 为什么 AddressableAssetsData 不进包也能工作？
Addressables 的默认配置对象通过 `EditorBuildSettings` 的 ConfigObject 引用，这是**项目级设置，不随 unitypackage 分发**。
ReunionMovement 的 `AddressablesSetup` 在编辑器打开时检测配置缺失并自动创建（`GetSettings(true)`），
且自动创建的分组/Label/Profile 与包内 `AddressableKeys` 地址约定**硬编码一致**，因此接收方无需任何手动配置。

### 地址约定（包内一致）
- UI 逻辑地址：`BuiltIn/UI/{UI名}`（对应 `AddressableKeys.UIRoot + UINames`）
- UI 物理目录：`AddressableAssets/BuiltIn/UI/`（迁移工具镜像生成）
- 分组名：`BuiltIn_*` / `Remote_*`（与 `AddressablesSetup.GroupDefs` 一致）

### 与接收方已有 Addressables 项目的兼容
`EnsureSetup` 为幂等补齐：只添加缺失的分组/Label/Profile，**不会**改动接收方已有的配置与资源分组。

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| 接收方导入后找不到 `AddressableAssetsData` | 正常，编辑器打开时自动创建；或手动执行「初始化配置」 |
| 运行时 UI 走的是 Resources 而非 Addressables | 未执行「迁移/UI 资源」；迁移后日志显示"从 Addressables 加载成功" |
| 构建 Content 报依赖错误 | 迁移工具已自动处理 Resources 内依赖；若仍有报错，把报错资源也加入迁移或检查是否引用了 Resources 内资源 |
| 接收方项目已有同名分组 | 幂等补齐不会覆盖；地址冲突时可在接收方 Groups 窗口调整 |
