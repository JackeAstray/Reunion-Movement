# 本地测试指南（无 CDN）

> 目标：不部署任何服务器，在本地完成 Addressables 的加载 / 释放 / 场景 / 更新链路验证。
> 默认 `LocalOnly` 模式完全本地，不联网。

## 1. 模式说明

| 模式 | 联网 | 数据来源 | 适用 |
| --- | --- | --- | --- |
| `Off` | 否 | 纯 Resources | 回归基线 / 关闭 Addressables |
| `LocalOnly`（默认） | 否 | 本地 Bundle（StreamingAssets） | 日常本地测试 |
| `Remote` | 是 | 本地 + CDN | 热更验证（需服务器，见远程部署指南） |

## 2. Editor 内测试（最快，推荐）

**无需构建**，直接在编辑器里跑：

1. 打开 `Window → Asset Management → Addressables → Groups`
2. 工具栏确认 **Play Mode Script** = `Use Asset Database (fastest)`
   - 此模式下运行时**直接读源资源**（`Assets/AddressableAssets/` 下的资源），不经 Bundle
3. （可选）执行迁移：`ReunionMovement → Addressables → 迁移 → UI 资源`
4. 点击 Play → 验证日志：
   - ✅ `LoadWindowAsync(StartGameUIPlane) 从 Addressables 加载成功`
   - ✅ `AddressableSystem 初始化完成 (Mode=LocalOnly)`
   - UI 正常显示、可交互

> 此模式适合日常功能开发，改资源即时生效，无需构建。

## 3. 真实 Bundle 测试（验证构建正确性）

模拟玩家实际加载路径：

1. 先执行迁移（同上）
2. 菜单 `ReunionMovement → Addressables → 构建 Content（当前平台）`
   - 确认构建成功，生成 `Build/Addressables/version.json`
3. Groups 窗口把 **Play Mode Script** 切到：
   - `Use Existing Build (local)` —— 直接读本地构建的 Bundle
   - 或 `Use Existing Build (virtual)` —— 虚拟加载（模拟 Bundle 但走源资源）
4. Play 验证：UI 从真实 Bundle 加载，`GetDebugStats()` 显示 `未释放=0`（无泄漏）

> 注意：切换 Play Mode Script 后需重新打开场景/重启 Play 生效。

## 4. 验证清单

- [ ] 启动界面通过 Addressables 加载（日志关键字：`从 Addressables 加载成功`）
- [ ] 打开/关闭多个 UI 后 `GetDebugStats()` 的"未释放"不增长（引用计数成对）
- [ ] 构建后 `version.json` 含 `platform`、`catalogHash`、`bundles` 列表
- [ ] `AddressablesMode.Off` 时行为与改造前完全一致（回归）
- [ ] 断网/Addressables 加载失败时 UI 自动降级 Resources（不崩溃）

## 5. 本地模拟远程更新（可选，Phase 3）

不部署真 CDN 也能验证 Remote 链路：

1. `GameConfig.addressablesMode` 切到 `Remote`
2. Groups 窗口把当前 Profile 切到 `DevLocal`（`http://localhost:8080/StreamingAssets`）
3. 构建 Content 后，在构建输出目录起静态服务：
   ```bash
   # 输出目录：Library/com.unity.addressables/aa/<平台>/
   cd "Library/com.unity.addressables/aa/StandaloneWindows64"
   python -m http.server 8080
   ```
4. Play：`Init()` 会发起 `CheckUpdateAsync`（日志：`远程更新检查: 无更新`），Remote bundle 从 `localhost:8080` 拉取

> 修改一个 Remote 资源 → 重新构建 → 刷新页面/重启 → 日志出现 `有更新待下载`，即可验证热更闭环。

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| Play 时报错找不到 catalog | 确认已构建 Content，且 Play Mode Script 选择与构建匹配 |
| WebGL 下无本地缓存目录 | 正常，WebGL 走浏览器 IndexedDB |
| 切换平台后构建产物路径 | 按 `[BuildTarget]` 分目录，切平台后自动对应新目录 |
| Editor 内偶尔加载到旧数据 | Play Mode Script 切换后重启 Play / 清 `Library/com.unity.addressables` 缓存 |
