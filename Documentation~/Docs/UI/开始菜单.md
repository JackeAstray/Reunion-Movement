# 开始菜单

开始菜单结构：

```text
开始页面
└─ 首页
   ├─ 开始游戏
   │  └─ 本地多人单机游戏
   ├─ 历史决策简报
   ├─ 设置（同一页）
   │  ├─ 音量（Slider）
   │  ├─ 分辨率（Dropdown + 全屏 Toggle）
   │  └─ 多语言切换（Dropdown）
   └─ 退出
```

## 1. 场景生成

Unity 菜单：

```text
ReunionMovement/UI示例/创建开始菜单与本地多人示例场景
```

生成：

```text
Assets/ReunionMovement/Editor/UIScenes/StartMenuExampleScene.unity
```

生成器代码：

```text
Assets/ReunionMovement/Editor/UIExamples/CreateLocalMultiplayerSelectionExample.cs
```

场景包含：

- `MenuRoot`：`CarouselMenuStack` + `StartMenuActions`；
- `StartPagePanel`：开始页面；
- `HomePanel`：首页；
- `StartGamePanel`：开始游戏；
- `LocalMultiplayerPanel`：本地多人单机游戏；
- `HistoryPanel`：历史决策简报；
- `SettingsPanel`：设置，包含主音量滑动条、分辨率下拉框、全屏开关、语言下拉框。

## 2. 层级与跳转

| 面板 | 选项 | 跳转 |
|---|---|---|
| 开始页面 | 开始 | 首页 |
| 首页 | 开始游戏 | 开始游戏 |
| 首页 | 历史决策简报 | 历史决策简报 |
| 首页 | 设置 | 设置 |
| 首页 | 退出 | 退出游戏 |
| 开始游戏 | 本地多人单机游戏 | 本地多人面板 |
| 开始游戏 | 返回 | 首页 |
| 历史决策简报 | 返回 | 首页 |
| 设置 | 上下切换设置行，左右调整数值 | 立即应用，停留设置页 |
| 设置 | 确认 | 切换“全屏”开关 |
| 设置 | 取消 | 返回首页 |

返回键（取消键）也会回到上一级面板；首页按取消不会退出。

## 3. P1 主导

- 所有普通菜单面板的轮播和设置面板控制器都注册为 `PlayerSlot = 0`，因此只有 P1 能操作菜单；
- P2-Pn 在普通菜单里没有输入目标；
- 只有进入「本地多人单机游戏」面板后，P1-Pn 的卡片才注册各自的 `PlayerSlot`；
- 本地多人面板内部所有玩家同时操作，流程见 [本地多人选择界面.md](./本地多人选择界面.md)。

## 4. 设置行为

设置全部在 `SettingsPanel` 一页内完成，由 `SettingsPanelController` 处理：

- 主音量：`Slider`，通过 `GameOption.SetMasterVolume` 实时应用并持久化；
- 分辨率：`Dropdown`，写入 `GameOption` 后走统一显示设置入口；
- 全屏：`Toggle`，通过 `GameOption.SetFullscreen` 切换窗口/全屏模式；
- 多语言：`Dropdown`（中文 / English / Русский / 日本語），通过 `GameOption.SetLanguage` 立即切换 `LanguagesSystem` 并持久化；
- 退出：`StartMenuActions` 监听菜单完成事件，编辑器停止 Play，打包后 `Application.Quit()`。

操作方式：

- 键盘/手柄/方向盘：上下切换设置行，左右调整滑动条或下拉框，确认切换全屏；
- 鼠标：直接拖动滑动条、点击下拉框、点击全屏开关；
- 取消键或右下角“返回”按钮返回首页。

## 5. 相关组件

- `CarouselMenuStack`：层级面板的打开/关闭/返回/分支跳转；
- `SettingsPanelController`：单页设置面板的音量、分辨率、全屏、语言；
- `StartMenuActions`：菜单退出；
- `LocalMultiplayerSelectionManager` + 玩家卡片：本地多人叶子面板；
- `LocalMultiplayerTrackView`：赛道位置颜色框 + `P#`。

> 旧的通用“多级轮播菜单示例”及其文档已移除；`CarouselMenuStack` 现在只作为开始菜单的层级栈实现保留。
> 场景仍需要游戏启动流程初始化 `UIInputSystem` / `UISystem`；单独打开场景 Play 可能只有 UI 没有输入。
