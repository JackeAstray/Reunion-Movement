# 本地多人选择界面（P1-Pn）

这个界面面向单机格斗/赛车游戏的角色、位置、颜色选择：

- P1-P4 卡片同时展示；
- 默认每人「不参加」；
- **每个玩家独立：选颜色 → 选位置 → 准备**；
- 单个玩家选完颜色后立即进入位置选择，不需要等其他人或 P1；
- 颜色**唯一**：已被占用的颜色对其他玩家置灰；
- 位置**唯一**：已被占用的位置对其他玩家置灰；
- 赛道的位置槽会显示玩家颜色框 + `P1/P2...` 标记；
- 准备后自己锁定，其他人仍可继续选择自己的颜色/位置；
- 所有已连接玩家都准备或已明确不参加后**自动读秒开始**；
- 选择界面内所有玩家都能操作，其他菜单仍只由 P1 操作。

## 1. 界面布局

```text
┌──────────────────────────────────────────────────────────────┐
│                        本地多人选择                          │
│                 选择颜色 → 位置 → 准备                       │
│                          3                                   │
│          选颜色后自动进入位置；所有玩家准备后自动开始          │
│                                                              │
│   ┌────────────┐  ┌────────────┐  ┌────────────┐           │
│   │  赛道区域   │  │  位置 1    │  │  位置 2    │  ...      │
│   └────────────┘  └────────────┘  └────────────┘           │
│                                                              │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐        │
│  │ P1  不参加    │ │ P2  不参加    │ │ P3  不参加    │  ...   │
│  │ 位置 [1][2][3][4]                                      │
│  │ 颜色 [不参加][■][■][■][■][■][■][■][■]                │
│  │        [ 准备 ]                                       │
│  └──────────────┘ └──────────────┘ └──────────────┘        │
└──────────────────────────────────────────────────────────────┘
```

- 画布参考分辨率 `1920 x 1080`；
- 四张卡片横向排列，每张约 `440 x 360`；
- 顶部显示当前阶段、倒计时和操作提示；
- 中间是赛道/位置示意，卡片内显示每个玩家当前选择；
- 赛道每个位置槽显示占用玩家的颜色框 + `P1/P2/P3/P4`；
- 颜色/位置唯一，因此一个位置正常情况下只有一个玩家标记；
- 每张卡片有位置按钮（4 个位置）、颜色按钮（不参加 + 8 色）、准备按钮。

## 2. 玩家数量与设备

`LocalMultiplayerSelectionManager` 每 0.5 秒读取一次
`UIInputSystem.GetConnectedDeviceInfos()`：

- 键盘/鼠标固定为 P1；
- 第一个实体控制器通常也是 P1（与键盘共享槽位）；
- 第二个控制器为 P2，第三个 P3，第四个 P4；
- 没有对应设备的卡片自动隐藏；
- 中途接入设备时，对应卡片自动出现；
- 中途断开设备时，该玩家状态释放，卡片隐藏。

如果只想按实体控制器数量显示（不算键盘/鼠标），关闭
`Include Keyboard Mouse As P1`。

> 一个方向盘可能在 Windows/Input System 里枚举成多个 HID 子设备
> （底座、踏板、轮缘等）。系统现在会：
> - 按 `manufacturer#serial`（没有 serial 时按 product）把它们归到同一个玩家槽位；
> - 过滤掉没有按钮/导航控件的纯轴子设备（例如踏板）；
> - 在 Console 打印 `设备路由：... → P1（product=...，serial=...，group=...）`。
>
> 如果仍然多出一个玩家，把这几行日志发出来，就可以按具体设备名继续合并。

需要固定“哪只方向盘/手柄是 P2”时，用：

```csharp
UIInputSystem.Instance.AssignPlayerSlot(device, 1); // 0=P1, 1=P2, ...
```

## 3. 每个玩家的流程

每个玩家**独立推进**，不需要等其他人，也不需要 P1 推进阶段：

| 当前行 | 玩家操作 | 结果 |
|---|---|---|
| Color | 选择颜色 | 参加，自动进入自己的 Position 行 |
| Color | 选择「不参加」 | 保持不参加，可以稍后重新选颜色 |
| Position | 选择位置 | 自动进入 Ready 行 |
| Ready | 确认准备 | 锁定自己，等待其他人 |
| Countdown | 全部锁定 | 自动倒计时 |
| Started | 全部锁定 | 开始游戏 |

- 颜色唯一：已被其他玩家占用的颜色在自己的卡片里置灰；
- 位置唯一：已被其他玩家占用的位置在自己的卡片里置灰；
- 选完颜色后立即可以选位置，不受其他玩家进度影响；
- 选完位置后立即可以准备；
- 一个玩家准备不会影响其他玩家继续操作；
- 所有已连接玩家都准备或已明确「不参加」后，自动倒计时；
- 需要恢复多人重复选择时，可打开 `Allow Duplicate Selections`，默认关闭。

P1 在这个界面里和其他玩家一样操作；P1 的“主导”只作用于其它菜单。

## 4. 输入规则

- 选择界面内：每张卡片注册一个 `PlayerSlot`，P1-Pn 同时操作；
- 其他菜单：只放 P1 的导航目标，P2-Pn 不注册；
- 方向输入：左右/上下都用于切换当前行的选项；
- 确认：
  - Color 行：选中颜色后自动切到 Position；
  - Position 行：选中位置后自动切到 Ready；
  - Ready 行：确认准备；
- 取消：
  - 准备前：清空当前玩家的颜色/位置，回到 Color 行；
  - 已准备：无效（已锁定）。

```text
选颜色 -> 自动进入选位置
选位置 -> 自动进入准备
准备 -> 等待其他已连接玩家
所有人准备/不参加 -> 自动倒计时
```

## 6. 组件配置

### LocalMultiplayerSelectionManager

| 字段 | 说明 |
|---|---|
| Cards | 按 P1-P4 顺序拖入 4 张卡片 |
| Position Count | 位置数量，默认 4 |
| Color Count | 颜色数量，默认 8 |
| Include Keyboard Mouse As P1 | 键盘/鼠标是否算 P1 |
| Allow Duplicate Selections | 是否允许多人选同一个位置/颜色，默认关（唯一占用） |
| Auto Start When All Ready | 全员准备自动读秒 |
| Countdown Seconds | 读秒时长，默认 3 秒 |
| Stage Label / Countdown Label / Hint Label | 顶部 UI 文本 |

### LocalMultiplayerPlayerCard

| 字段 | 说明 |
|---|---|
| Player Slot | 0=P1，1=P2，2=P3，3=P4 |
| Position Buttons | 依次对应位置 1..N，不含「不参加」 |
| Color Buttons | 第 0 个是「不参加」，后面依次是颜色 0..N-1 |
| Ready Button | 准备按钮（选完颜色/位置后可用） |
| Ready Badge | 已准备指示色块 |
| Background | 卡片背景（准备后变绿） |

### LocalMultiplayerTrackView

| 字段 | 说明 |
|---|---|
| Manager | 对应的选择管理器 |
| Slots | 4 个位置槽；每槽有 Markers（颜色框）和 Labels（P1/P2 文本） |
| Colors | 与颜色索引一一对应的颜色，用于位置槽标记 |

## 7. 和其他 UI 的关系

- 选择界面用本文的 `LocalMultiplayerSelectionManager` + 玩家卡片；
- 设置、暂停、确认弹窗等普通菜单继续用
  `CarouselSelectionController` / `CarouselSelectionGroup`，并只给 P1 注册输入；
- 选择界面关闭后，卡片随面板一起禁用，P2-Pn 的焦点域目标自动注销；
- 如果选择界面是独立 `UIController` 窗口，建议在窗口根节点挂 `UIFocusScope`。

## 8. 当前假设

- 位置和颜色默认**唯一占用**；需要允许重复时打开 `Allow Duplicate Selections`；
- 选择阶段中途接入的设备可以加入；倒计时开始后才接入的设备不参与本局；
- 选择界面是全局模态：一个玩家打开选择界面会挡住其他窗口；
- 赛道位置槽按玩家选择的颜色显示标记；唯一占用时一个位置只有一个 `P#`；
- 鼠标点击同样受占用/准备状态校验，但不能替代手柄/方向盘的焦点导航。
